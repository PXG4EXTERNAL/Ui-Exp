# UILibrary — Assets

Upload your PNG files here. The library fetches them directly via HTTPS —
no Roblox asset IDs needed.

## Required files

| File | Used for |
|------|----------|
| `tab-all.png` | "All" tab sidebar icon |
| `tab-audio.png` | "Audio" tab sidebar icon |
| `tab-gameplay.png` | "Gameplay" tab sidebar icon |
| `tab-graphics.png` | "Graphics" tab sidebar icon |
| `tab-units.png` | "Units" tab sidebar icon |
| `tab-enemies.png` | "Enemies" tab sidebar icon |
| `tab-misc.png` | "Miscellaneous" tab sidebar icon |
| `tab-keybinds.png` | "Keybinds" tab sidebar icon |
| `tab-testing.png` | "Testing" tab sidebar icon |
| `search.png` | Search bar icon |
| `close.png` | Red × close button |
| `section.png` | Section header icon |
| `check.png` | Toggle ON state (green ✓) |
| `cross.png` | Toggle OFF state (red ✗) |
| `teleport.png` | Button default icon |

## Notes

- Recommended size: **64 × 64 px** or **128 × 128 px**, square PNG with transparency.
- Make sure **HTTP Requests** are enabled in your game's Security settings (Game Settings → Security → Allow HTTP Requests).
- After uploading, no code changes are needed — the library automatically picks up the new files from this folder.
